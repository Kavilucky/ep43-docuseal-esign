# DocuSeal вместо DocuSign: свой сервис подписания документов (Docker Compose, PostgreSQL)

Набор к ролику «DocuSeal: независимый сервис онлайн-подписания документов взамен DocuSign». Клиент получает ссылку, открывает её в браузере и подписывает на экране, приложение не нужно. DocuSeal работает у вас на VPS в Docker Compose с базой PostgreSQL и HTTPS через Caddy. Без абонентской платы за сервис: платите только за сервер.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep43-docuseal-esign && cd ep43-docuseal-esign
```

## Что внутри
| Файл | Для чего |
|---|---|
| `docker-compose.yml` | DocuSeal (`docuseal/docuseal`), PostgreSQL 16 и Caddy с HTTPS; данные на постоянных каталогах `pg_data` и `docuseal` |
| `.env.example` | пример файла настроек: домен, пароль базы, ключи шифрования `SECRET_KEY_BASE` и `ENCRYPTION_SECRET` |
| `backup.sh` | резервная копия: дамп PostgreSQL и архив файлов (правило 3-2-1) |
| `Инструкция.txt` | пошаговый запуск и честные ограничения |

## Быстрый старт
1. Нужен VPS с Linux, Docker и Docker Compose и домен с A-записью на IP сервера (порты 80 и 443 открыты).
2. `cp .env.example .env`, сгенерируйте значения (`openssl rand -hex 64`) и впишите домен.
3. `docker compose up -d`, затем откройте `https://ваш_домен` и создайте администратора.
4. Загрузите шаблон, добавьте поле подписи и подпишите тестовый документ с телефона.

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек на живом сервере **не запускал**. Образ `docuseal/docuseal:latest`, пути `/data` и `/var/lib/postgresql/data`, переменные `DATABASE_URL`, `SECRET_KEY_BASE`, `ENCRYPTION_SECRET`, `FORCE_SSL` и команду Caddy сверьте с [репозиторием DocuSeal](https://github.com/docusealco/docuseal) и документацией; после первого запуска закрепите версии.
- `SECRET_KEY_BASE` и `ENCRYPTION_SECRET` задаются один раз и не меняются (по руководствам по самохостингу ими шифруется ключ центра подписи). Копия `.env` хранится отдельно от сервера.
- Без постоянных каталогов (`pg_data`, `docuseal`) данные исчезнут при пересоздании контейнеров.
- Простая электронная подпись в России действует по соглашению сторон (63-ФЗ; автор опирался на обзоры, текст статьи 6 не сверял). Значимые документы и требования к форме проверьте у юриста. Это не юридическая консультация.
- По разным источникам API, вебхуки, брендирование и часть функций относятся к платной лицензии Pro; единого официального подтверждения автор не нашёл. Проверьте на docuseal.com. Лицензия DocuSeal AGPLv3 с дополнительными условиями: не убирайте атрибуцию.
- Цены DocuSign в ролике (Standard около 30 $ за пользователя в месяц, около 360 $ в год, около 100 конвертов) оценка по обзорам 2026 года; проверяйте на docusign.com. Скорость подписи («за пару секунд») автор не замерял; журнал подписания и хэш документа в этом наборе не проверялись.
- Резервная копия по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено.
